# Сапёр — как запустить игру на своём компьютере

Это твой первый веб-проект: классический Сапёр на Next.js + React.

## Что нужно заранее

1. **Node.js версии 20 или новее.** Проверь в терминале:

   ```powershell
   node -v
   ```

   Если показывает v20.x, v22.x или выше — всё хорошо.
   Если Node нет или версия старая — скачай LTS-версию с сайта https://nodejs.org и установи (все кнопки «далее» без изменений).

## Запуск за 4 шага

1. **Распакуй архив** в папку `Documents` (правый клик по архиву → «Извлечь всё...»).
   Получится папка `C:\Users\OBO24\Documents\saper`.

2. **Открой терминал в этой папке.** Самый простой способ:
   открой папку `saper` в Проводнике, кликни в адресную строку сверху,
   сотри путь, напиши `powershell` и нажми Enter.

3. **Установи библиотеки** (один раз, нужно подключение к интернету):

   ```powershell
   npm install
   ```

   Скачаются Next.js, React и пара вспомогательных библиотек — всё, что перечислено в `package.json`.

4. **Запусти игру:**

   ```powershell
   npm run dev
   ```

   Открой в браузере адрес **http://localhost:3000** — играй!

## Полезно знать

- **Остановить сервер:** Ctrl+C в терминале.
- **Запустить снова после перезагрузки:** зайди терминалом в папку проекта и снова `npm run dev`. Установка библиотек больше не нужна.
- **Терминал должен оставаться открытым**, пока играешь — в нём работает сервер.
- `npm run build` — «сборка» проекта перед публикацией (понадобится для Vercel).

## Структура проекта

```
saper/
├── package.json          ← список библиотек и команд (как requirements.txt)
├── next.config.ts        ← настройки Next.js
├── tsconfig.json         ← настройки TypeScript
├── src/
│   ├── app/
│   │   ├── page.tsx      ← ИНТЕРФЕЙС игры (React-компоненты)
│   │   ├── layout.tsx    ← общая оболочка страницы
│   │   └── globals.css   ← стили и цвета
│   ├── lib/
│   │   ├── minesweeper.ts  ← ЛОГИКА игры (правила, мины, «аккорды»)
│   │   └── utils.ts        ← маленькая вспомогательная функция
│   ├── components/ui/    ← готовые кирпичики интерфейса (кнопка, вкладки...)
│   └── hooks/
│       └── use-toast.ts  ← всплывающие уведомления
```

Подробное объяснение каждого файла — в методичке «Проект „Сапёр"», глава 8.
